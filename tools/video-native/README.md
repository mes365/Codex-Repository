# VideoNative Win11 x64
Native Windows C++ Win32 and Media Foundation video processor. No Python, Qt or FFmpeg runtime needed.
Features: MP4 H264 transcoding, normal metadata not explicitly propagated, file MD5, experimental invisible spatial mark.
C2PA warning: no guaranteed removal of remote or externally bound credentials. No forensic watermark extraction or verification in this build.
Build: GitHub Actions workflow **Build VideoNative Win11 x64**, or CMake Visual Studio 2022.
Result: Actions -> run -> Artifacts -> VideoNative-Win11-x64.
Limitations: Windows codec availability and video format compatibility vary. First build and video sample test required.
