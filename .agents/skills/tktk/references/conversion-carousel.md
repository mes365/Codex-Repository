# 商品推广套图：首张建立购买动机，后页增加决策价值

完整套图与续图时读取。先按 [first-slide-conversion.md](first-slide-conversion.md) 设计首张；受众与主行动按 [engagement-and-learning.md](engagement-and-learning.md) 的对应部分处理。默认五页是交付约定，用户数量和用途优先；不要求每件商品采用叙事、反转或同一种页序。

## 选择内容形式

从真实商品事实、购买者、使用者和购买情境选择一个主购买理由。根据可用证据和静态可读性选择形式：

| 形式 | 适用条件 | 页面如何增加价值 |
| --- | --- | --- |
| 直接展示 / 可见细节 | 外观、图案或结构足以支持偏好 | 首张点明用途或表达，后页补完整展示、局部和相关情境 |
| 送礼 / 身份认同 | 商品确实能表达关系、兴趣或身份 | 首张让买家认领送礼用途，后页补图案含义、展示和使用情境 |
| 用途 / 选择帮助 | 已知功能或结构能回应具体需要 | 首张呈现已知价值，后页解释可见依据和适用限制；AI演绎不当实测 |
| 对比 / 清单 | 有真实、可比的选项或多条有用信息 | 首张指出具体选择问题，后页逐项补充，不虚构优于竞品的结论 |
| 日常幽默 / 情境互动 | 商品图案或用途本身参与笑点 | 首张产品与购买意义已成立，后页通过不同动作、细节或反应兑现 |
| 简短叙事 / 温情 / 反转 | 具体生活事件能增强商品相关价值 | 首张就有购买动机，后页发展事件；不靠隐藏商品与核心理由维持悬念 |

这些是选择方法，不是批量轮换菜单；可组合但不堆叠。没有功能证据时可以围绕设计、兴趣或礼物意义，不制造痛点和疗效。角色、活动和场地只在所选形式需要时加入，不能强行让所有商品都由一家人演绎。

## 页面规划

先写一句主购买理由和首张表达，再规划余页。后页可补完整商品视图、关键印花/结构、适用情境、选择信息、相关幽默或一个购买邀请；按本件商品的信息与情境安排，不固定第3页细节、第4页揭晓、第5页合照。

示例节奏：首张“商品＋目标买家价值”，后页依次补清楚展示、一个新细节、适用情境和同一主行动。也可以细节先行，或用实际互动推进；这不是必须复制的五页表格。至少一页正面完整清楚展示核心特征，其他页不强制全身正面或完整读出全部印花。首张仍需满足本次主理由所需的商品可读性，不能以“后面有证据页”为由放宽。

购买 CTA 可在合适的页面或 caption 中出现，不限定只能末页。首张已有购买理由时，余页继续补有用信息，不必用悬念阻止观众直接购买。每页一个主信息点，短句用自然美国英语，不把所有页面都写成疑问或夸奖。

生成前保留紧凑计划：页号｜本页决策价值｜画面场地/景别/机位｜商品可见部分｜动作（需要时）｜与前页新增什么｜准确英文叠字。反转线索只在采用该形式时记录。不要新增用户未要求的短片时码、对白和环境声交付。续图继承已有商品、人物和目标，新增信息，不把旧页重生计入新增。

## 情境与视觉变化

有活动时先明确具体事件与起止状态，再选合理场所；展示类则按产品信息选择视图，不强造事件。按内容安排全景、中景、细节、侧拍或肩后视角，无需五页各一种镜头或每页换地点。用户指定的场景与风格优先。

相邻页比较信息、人物位置、主要动作、景别和商品展示；只变眼神、嘴角或叠字通常不足以支撑连续五页。不同角度若展示了实际新细节可以有价值，不机械以姿势变化评分。事件全景不要同时要求印花占满画面；细节页不要同时要求全家全身出现。

同套固定商品和已出现人物身份，不固定姿势、家具、机位或光线方向。换地点应有合理的用途或活动转换；衣着、天气、成人支撑与儿童能力相符。多商品、续图和同质化复盘读 [batch-diversity.md](batch-diversity.md)。

## 可选叙事与反转

确有具体事件时可用日常共鸣、克制温情、冷面荒诞或融合，借助人物选择与可见动作推进。没有合适反转就用商品细节或幽默回报；不把所有套图改成同一送花、等抱娃或分糖情节。

反转只改变对已有细节的理解，不延迟商品核心购买理由。事先安排一个可在成图中辨认的线索，在合理后页回收；复杂形式需要更多线索时先检查页数和画面容量，不能套用固定页码。不能由末页突然出现的陌生人、身世、医疗结论或未知功能完成转折。文字不伪造恶意或事故，也不能补救没有画出的关键动作。

温情依靠具体关系和克制反应，幽默保留尊重。人物有愿望与选择，商品仅完成已知用途内的小动作、表达或兴趣认同；不让商品修复亲子关系、消除贫穷、治愈疾病或改变人格。涉及衰老、疾病、贫穷和残障时不把人物变成卖货苦难道具。普通生活足以表达价值。

自然感来自与活动一致的眼神、承重、接触和微表情；不强迫每页看镜头微笑，不用模糊、噪点和残缺手部模拟真实。AI场景不冒充客户评价、实测或真人纪录。

## 叠字与安全位置

叠字按 [hook-typography.md](hook-typography.md) 决定。通常一到两行，语义完整；用户明确长文时按范围安排。文案与商品印花分离，完整字块含描边和阴影均避开画面边缘、主要商品、脸和重要动作。竖屏工作构图可从横向约12%–78%、纵向约16%–30%的留白起步，顶部约12%、底部约23%和右侧操作区尽量留空；被商品或脸占用时改用其他安全留白，不能机械压在头顶。这是保守布局建议，不是平台统一像素规范，设备和入口会变化；未做发布界面预览不得宣称界面适配已验证。

音乐只辅助，图与字独立表达。原生图文按信息变化设计，不承诺固定每页时长、音乐切入或视频前三秒留存率。用户明确改成视频时再规划可执行的时序和声音，沿用授权边界。

## 成图验收

首张独立验收通过后才作为合格锚点展开；再分别记录商品与技术、购买价值与内容兑现、视觉变化。用实际页号说明证据，不能用文件存在、哈希差异或拼写正确代替创意验收。暂不看叠字时检查画面是否真的呈现所需动作/特征；再合并文字检查表达，不要求所有价值都由人物动作表达。

检查每页新增什么、首张理由是否明确、商品信息是否真实、期待是否兑现、主行动是否一致。反转时再查线索和回收，未采用该形式不要求伏笔。关键商品或动作失败时按主技能一次自动修复额度处理；仍失败就标记未完成，不能只改 Hook 将失败重新命名为成功。

标题、caption、30字符以内产品名、标签和配乐按主技能交付。记录买家/购买动机、首张方案与选择理由、后页新增价值及实际检查；未提供数据时只能称为待验证的创意方案。
