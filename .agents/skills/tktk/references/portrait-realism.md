# 日常手机摄影、真人感与成图验收

生成或检查摄影图片时读取。这里判断所选摄影方式是否落实，不凭广告感判定图片一定由AI生成，也不把自然感当作成交证据。外部方法来源见末尾；不增加外部运行依赖或改变内置 `image_gen` 流程。

## 先选摄影方式，再写细节

人物互动、穿着、手部演示、商品主体是内容选择；摄影方式是另一项决定。生活场景默认采用日常手机记录；较整洁的创作者演示和明确的商品展示按页面信息需要使用，用户指定棚拍等风格时优先遵从。商品近景可以是认真拍摄的展示，不必伪装偶然抓拍。同套保留人物与商品身份，允许拍摄条件随实际位置变化，不要求每页同样温暖、虚化或精致。

先解决拍摄关系、动作与环境，再选约3–5个与本页风险相关的可见线索。商品保真、人物身份、承重安全和画幅是硬约束，不占线索名额。不要把candid、smartphone、RAW、某手机型号当成效果保证；设备词不证明真实设备、EXIF或RAW文件。9:16写入画面要求，工具未暴露尺寸参数时不声称锁定精确像素。

## 拍摄者、光线、动作与环境

| 决定 | 提示词应明确的内容 | 常见冲突或误用 |
| --- | --- | --- |
| 谁在拍 | 他拍、自拍或镜自拍；人物画面说明拍摄者在可到达的位置、持机高度/朝向，以及为什么记录此刻。商品页说明手持或摆放与机位即可 | 同时持机、抱娃、双手展示；无人可站的角度；混写自拍与他拍。镜面反射仅在有镜子时检查，不无故增加人物或设备 |
| 现场光线 | 先确定窗、门、灯或户外条件，再写受光、投影和接触阴影。允许正常局部明暗及色温差，同时保留商品准确颜色与必要信息 | 每张都柔和暖光、所有对象都理想曝光；普通房间却加整套棚拍轮廓光；为真实感故意欠曝 |
| 景深与取景 | 按位置、距离与页面任务控制背景分离，日常画面可让附近桌椅、门框与活动环境可辨。构图来自实际可实现的视角 | 全部85mm式奶油虚化；反过来规定所有手机照全画面锐利；强制歪斜、截头或模糊 |
| 动作与表情 | 一个活动触发的动作，如调整支撑、拿起衣服、听家人说话；眼神有对象，人物反应可以不同步，安静或普通表情也成立 | 全员同时灿笑、五页同一抱姿；强迫永远看向镜头外；刻意演“不摆拍”或增加危险动作 |
| 环境与物件 | 普通且符合用途的空间，少量活动相关物件；整洁也可以真实，使用状态要有原因 | 所有道具配色协调、背景自动变漂亮庭院；用随机杂物、污渍和噪点充当生活感 |
| 人脸、头发与衣物 | 与年龄/距离相符的肤色变化、正常眼睛反光和不完全规则的发束；动作产生真实张力、褶皱及遮挡 | 给婴儿成人毛孔和皱纹、给老人夸张粗糙皮肤；过度美颜、全局锐化、塑料发丝 |

用可拍到的事实代替空泛质量词。不要在同一页叠加“普通手机瞬间、奢华人像镜头、完美柔光、无干扰背景、全部正面印花清楚、巨大顶端留白”等冲突要求。轻微颗粒、手持偏差或运动模糊仅在有具体用途时选用，不是必备真实线索。

## 商品与文案不把照片锁成广告模板

原商品图始终负责颜色、轮廓、结构、印花布局与准确拼写。服装印花随布面的透视和张力变化，不能像后贴的刚性矢量标签；褶皱和局部遮挡服从动作，同时保证首张主购买理由所需特征可辨、整套至少一页完整清楚展示核心特征。不能以真实感为由改字、镜像图案或毁掉购买信息，也不强制每页正面全身和全部长印花可读。

细节页写清“画面必须出现什么、哪些整件边界在取景外”：例如印花近景排除领口/袖口/裆扣，以可见字形和布面为主体；按扣页包含开合接触和包边。只保留局部可见文字的准确性，不把“完整展示整件、所有印花全部可读”的证据页要求复制进去。整套仍有完整商品页；近景也不能切掉本页主卖点或叠字而妨碍阅读，不为裁切故意改动原印花。

先构思一个成立的照片，再为准确短文案选择可读区域。同套保持字体家族、层级与强调逻辑，位置不必相同；先删冗余字，再移动字块，必要时用紧凑小底板，不为每页标题清出同样的浅墙或把主体都压低。细节见[排版参考](hook-typography.md)。默认仍一次内置生图同时完成照片和叠字；不自动新增无字背景、后期合成或额外测试图片。

## 锚点分工与连续性

首次出现且通过验收的人物页建立身份卡：脸型、发型、年龄感、衣着及相关配件；商品参考负责商品，相关合格页才负责本次摄影方式。首张只展示商品时不建人物卡，后页出现人物才建立，不增加张数。记录必要地点、物件与时间关系；姿势、距离、机位和光向是逐页变量，不全塞进身份卡。

身份卡以**实际验收的成图**为准，后页草稿先替换再提交。例如初稿写 navy polo，而合格图实际为 charcoal crew-neck T-shirt，则删除所有旧 polo、纽扣领、抓衣领等冲突描述，改写实际圆领 T 恤及相应抓握动作；不靠末尾加“参考优先”抵消前文。明确指定的人物/衣着未实现时先判定是否需要本页修复，不能用身份卡悄悄放弃用户要求。身份卡通常只需一行，含面貌、头发、成人衣服、婴儿相关配件与合格锚点路径。

首图另按[首张参考](first-slide-conversion.md)检查独立购买表达，并按本文件检查所选摄影方式。日常手机目标下仍明显像广告样片，不能作为合格风格锚点扩散。用户已有核准图且符合当前目标时直接复用；用户改要手机感而旧图偏商业摄影时，旧图可仅作身份依据，不能同时要求复制其打光、虚化和版式。不要因此擅自重做未被请求的旧页。

后页保留人物身份和原商品，改变与页面信息相关的动作、身体位置、景别及机位。同地点维持物件关系，换机位后画面左右光向可变化，换场则重新描述可用光。用户未指定的人物属性不机械继承上一商品；明确指定同一家庭时保留。原商品持续随调用传入，不能只凭生成图累积印花误差。

## 成图验收与修复

缩略看整体摄影方式、购买表达和文字层级；放大看细节。只在实际查看后记录检查，不声称做过未实施的手机预览、平台界面或眼动测试。

1. **商品与文字**：颜色、剪裁、已知面、印花大小/布局及拼写对照原图；关键购买信息与Hook可读，叠字未变成衣服印花。
2. **身份与物理关系**：人物身份连续；拍摄者位置、手臂归属、抓握、婴儿支撑、重心、视线、透视、接触阴影与褶皱成立；有镜面时再核对反射。
3. **局部摄影细节**：皮肤/眼睛/头发/衣物边缘符合年龄和距离，照明来自本页环境；不靠磨糊、噪点或锐化隐藏问题。
4. **整张摄影方式**：暂时忽略叠字，这是否像从所述位置拍到的实际活动或展示？日常手机页若仍靠完美布景、同步笑容、统一理想布光与整齐标题留白组成广告样片，记录“摄影风格未达目标”，不能仅因手指与文字正确就通过。明确商品展示/棚拍页按所选方式判断，不因精致自动失败。
5. **相邻页与买家价值**：身份相同不等于姿势复制；比较实际动作、位置、景别与新增信息，关键商品信息不能被真实性效果牺牲。摄影自然与购买动机清楚分别验收。

只有现有图修复时才按需要锁定姿势、裁切与机位，不把锁定词复制到下一新页。局部缺陷最小编辑；整张摄影方式或关键动作未实现时，先消除冲突要求，再在本页额度内调整构图或重生。风格修复不能同时要求原来的理想布光、虚化和版式全部不变；无关的身份、原商品和准确文案继续保留。

所有原因共用主技能的**每页一次自动修复**，局部编辑与重生均计入；不能以新增风格检查重新获得次数。仍失败就记录具体未完成项，保留其余成功文件；不自动增加候选、重做整套或设置新的确认环节。提示词与目视验收不保证真人效果、平台识别结果或转化，也不将AI场景冒充真人经历/评价。
