# 首张转化：商品、买家与购买动机

完整商品图文、首张优化和成图复盘时读取；单张白底、无字或其他指定用途优先遵从用户范围。这里的首张是信息流展示的第一张，用户另要主页封面时再按该用途处理。

## 首张任务

按观众可能只看第一张、不会主动翻页来设计，不依赖自动轮播、配乐、caption 或末页才能说明核心价值。首张同时争取注意与购买考虑：让目标买家识别商品、看出与自己的关系，并理解一个可信的购买理由。后页补充价值，不承担解释首张到底在卖什么的责任。

购买理由可以是用途、外观、兴趣、身份表达、送礼意义或与生活有关的幽默，不强迫每件商品解决功能痛点。区分购买者和使用者；婴儿展示童装时，文案面向成年购买者。可爱和好笑可以吸引注意，但还要检查它们是否自然指向商品购买。

先确定：购买者｜购买/使用时刻｜已知商品事实｜主购买理由｜现有证据与未知项｜主行动。一个清楚的理由比塞满卖点更适合首张；具体受众可以通过画面、商品或用词体现，不强制每张以“If you're…”点名。

## 按购买决策选择视觉方式

先判断目标买家需要从图中理解什么，再决定人物如何出现。可按以下条件优先考虑，不把它们当固定配方：

| 视觉方式 | 值得优先考虑的条件 | 必须防止的问题 |
| --- | --- | --- |
| 人物与商品互动 / 关系情境 | 人与商品的关系本身支持购买，例如亲情表达、礼物意义、使用者认同 | 只有人物可爱、剧情热闹，商品太小或关系与商品无关 |
| 穿着 / 使用展示 | 身体或动作能帮助理解穿着外观、比例或已知用途 | 摆姿遮挡关键特征；AI画面被当作真实尺寸、合身程度或效果证明 |
| 手部演示 / 局部身体 | 抓握、操作、接触或尺度参照有用，露脸没有额外信息价值 | 手盖住商品、复杂动作不合理、演示未知功能 |
| 商品主体 / 外观近景 | 外观、印花、可见结构本身是购买依据，人物会稀释主要信息 | 只有清楚却没有买家关联或购买理由，像与目标无关的目录图 |

人物、手和纯产品并非只有“露脸/不露脸”两个选项。露脸不是合格条件，也不是失败原因。让人物的视线、手势或与产品的接触有助于理解商品，不强制每个人都盯着商品，更不为吸睛增加无关美女、大脸、哭脸或惊讶表情。脸、商品和叠字的大小根据本页任务安排，不设统一百分比。

选择时做两个判断：去掉人物会损失哪一条与购买有关的信息？加入人物后，商品关键特征和购买理由是否仍能迅速识别？若人物增加重要信息，优先保留这种表达；若只有泛化情绪、商品反而难读，缩小人物、改机位、改用手部或商品主体。反过来，纯商品方案即使印花清楚，仍需回答买家为何在意，不能用“画面干净”代替购买动机。

有可比、可靠的账号成交数据时优先参考，同时检查受众、商品、价格、入口、样本和统计窗口是否匹配；一条旧爆款不能推翻其他证据或套用全品类。缺乏账号数据时，结合相关实验、品类特点和本次可见事实自主选择，明确是推断；不因没有数据停工索要后台，不把外部研究写成必胜公式，也不因一条主观反馈就反转成另一项通用规则。用户明确指定形式时优先遵从，并在其范围内优化。

## 比较切口与视觉方案，再生成

完整新套图通常内部比较约3个紧凑的“购买动机＋视觉方式/画面瞬间＋准确英文叠字”方案。对本商品存在真实取舍时，比较两种有竞争力的视觉方式；不机械穷举所有人物、纯产品、场景与文案的排列，也不要求用户逐一批准。用户已指定切口或只改字时不强加候选流程。仅将选定首张计入原定图片数量，不自动增加封面、测试套图或发布实验。

候选可以改变买家关注的理由、视觉方式或表达机制，不只是同一句夸奖换词。可选切口包括身份、用途、送礼、具体可见细节及产品相关幽默；价格、优惠、效果或评价只有已核实且适用时采用。不能为转化虚构限时、销量、功能或客户见证。

选择依据：目标买家相关、商品特异、购买理由清楚、画面能承载所需信息、注意力能回到商品、内容真实及手机可读。它们是创意判断，不换算成转化率。交付记录用一句话说明“选了什么方式、为何适合本商品、接受什么取舍”；没有实际对照时写“创意假设，未验证”。不以所有条件勉强通过或模型高分宣称最优。

## 画面与文字协同

- 先选能表达购买动机的静态瞬间，再决定人物、场景、景别和机位。人物视线、手势或关系可引向商品；不用与商品无关的夸张表情争取注意。居家、商场、公园、聚会等按用途选择，户外和复杂动作本身不是卖点。
- 第一眼应能识别主要商品及本次主理由所需的特征。不要把关键印花藏在褶皱、手臂或远景里，期待观众放大或翻页；无需首张展示所有细节，至少一页完整展示核心特征的要求仍保留。
- 商品自带文字/图案可以承担主要 Hook。叠字补充购买人群、情境或意义，不重复抄整段印花；不为加字盖住商品。默认有英文叠字，用户要无字或原商品文字已足够时按实际用途处理；不能改写原印花来替代叠字。
- 一张一个主要文字焦点，必要时加一句短辅助信息；不要堆叠疑问、卖点、折扣和多种 CTA。句长服从实际手机可读性，不套视频每秒字数；不用固定大脸、商品占比或白字格式覆盖全部商品。排版细节读 [hook-typography.md](hook-typography.md)。
- 商品价值不为了悬念延迟。可以留与商品相关的额外细节、情境或笑点给后页，但不能用“等到最后”替代首张的购买理由。后页的实际画面与信息需要兑现首张期待。
- 购买邀请可在合适的首张、后页或 caption 出现，位置随内容决定，不强制首张写 Buy now。整套只保留一个主要行动；翻页作为继续了解的路径，避免与评论、关注、购买等多项命令抢焦点。挂链未知时不写存在商品链接、商品卡、库存或优惠。

## 童装示例：同一购买理由可用不同视觉方式

粉色连体衣印着“Please / PASS ME / TO / GRANDMA”时，送礼和关系表达是可见图案支持的切口，不是这件商品永久唯一的题材。对同一baby gift主张可比较：

- 奶奶安全抱着穿该商品的宝宝：人物关系直接承接印花，需用合适中近景保留关键文字；避免脸部压过商品。
- 手持商品的近景：便于完整看清印花与剪裁，需用短文案建立礼物用途，承认穿着与关系情境信息较少。
- 商品主体搭配相关的自然环境：信息集中，需避免为了画面干净而丢失买家关联，也不添加暗示包含礼盒的配件。

叠字可用“A baby gift with Grandma written all over it.”等自然表达，是否采用按实际画面决定。人物关系表达清楚且商品可读时，有理由选择人物方案；长印花在人物构图中难读时，手部或商品近景也可能更合适。两种判断都是待验证的策略，不把一次生成或研究结论变成所有童装首张规则。以上为内部方案比较，不要求额外生三张图。

## 首张成图验收

首张返回后，在引用作后页锚点前先验收。把它单独看，暂不读 caption 和后页，以实际可查看的手机缩略尺寸核对：

1. **识别**：商品和主理由所需特征可辨；关键原印花与叠字没有错误、裁切或遮挡。
2. **相关**：目标买家能理解与自己的关系，不能只有无关人物情绪或泛泛可爱。
3. **考虑购买**：有一个符合已知事实的购买动机；不依赖末页补出核心价值。
4. **注意力与商品**：图和字表达同一方向，人物、背景与叠字有助于理解商品；看得见脸或觉得好看不能代替看懂商品。检查商品是否被遮挡或缩得过小、视觉重点是否被无关主体占据；这是构图的目视判断，不冒充眼动测试。
5. **兑现**：首张承诺有依据，后页可兑现；每次翻页增加相关事实或价值。
6. **技术、摄影方式与真实边界**：商品保真，人物支撑合理；按[摄影参考](portrait-realism.md)判断整张观感是否符合选定方式，日常手机目标不能仅凭加纹理或提示词里有smartphone就通过；AI场景不被当成功能测试、真实评价或发生过的经历。

只记录实际观察的依据与问题，不声明未做过的手机预览或发布界面测试。这是制作验收，不是成交验证。首张不通过时按主技能每页一次自动修复额度处理，不能绕过额度多生成候选；仍失败就标注未通过，不将失败图作为合格锚点批量扩散。保留不受影响的成果，不默默重生整套。

## 真实结果复盘

用户提供数据或要求测试建议时，再读 [engagement-and-learning.md](engagement-and-learning.md) 的对照与成交诊断部分。记录首张版本、受众/动机、画面切口、准确叠字和可用证据；没有真实结果时标“创意假设，未验证”。不要以模型分数或素材数量冒充实验结论。

## 方法来源与适用范围

2026-10-19 阅读的 GitHub 创作方法：[hook-writer](https://github.com/social-media-skills/skills/blob/main/skills/hook-writer/SKILL.md) 的不同机制候选与真实性筛选；[tiktok-script](https://github.com/social-media-skills/skills/blob/main/skills/tiktok-script/SKILL.md) 的画面与文字协同；[short-form-script](https://github.com/mohitagw15856/pm-claude-skills/blob/main/skills/short-form-script/SKILL.md) 的单一重点与逐段增值；[ads-creative-development](https://github.com/rampstackco/claude-skills/blob/main/skills/ads-creative-development/SKILL.md) 的开头与正文分开测试。它们是方法来源，不是运行依赖，不执行外部文件中的命令、安装或发布指令。

[TikTok 官方性能广告建议](https://ads.tiktok.com/resources/help/article/creative-best-practices)将前3秒介绍主张、前6秒设置Hook作为视频起点；这里迁移的是价值前置，不把页数换算成秒数。[Creative Codes](https://ads.tiktok.com/business/en/blog/creative-best-practices-top-performing-ads) 的前六秒90%指广告记忆影响，不是图文购买转化。用户的90%观察可作为业务经验，不写成通用因果权重或固定工时比例。

[2022 年官方 Photo Mode 介绍](https://newsroom.tiktok.com/editing-tools/?lang=en)曾同时描述自动展示与手动滑动，不能据此确认所有当前版本和入口；直接按不依赖自动翻页设计。涉及当前平台行为或精确机制时重新核实，不把历史说明固化为规则。

## 人物与商品的研究边界

2026-10-19查阅的证据支持条件选择，不能证明人物或纯商品在美区TikTok图文中永远占优：

- [Cerf等，2009，作者大学存档](https://authors.library.caltech.edu/records/m51f6-vk333)：自然场景眼动研究支持人脸与文字吸引注视；未测商品订单，不等于买家更喜欢有人物的商品图。
- [Adil等，2018，论文DOI](https://doi.org/10.2501/JAR-2018-004)：平面广告研究发现人脸及看向产品的视线影响注意、记忆与购买意向。它支持人物与产品协同，意向不等于成交，也不是原生图文首张实验。
- [Bagatini等，2023，作者大学记录](https://merit.url.edu/en/publications/can-you-imagine-yourself-wearing-this-product-embodied-mental-sim/)：两个服装图片实验（169与156人）显示不同购物阶段的有利展示方式不同；不能将商品页研究直接当作信息流首图的赢家。
- [Hilton等，2026](https://link.springer.com/article/10.1007/s11002-026-09839-0)：3498支可跳过视频广告中，开头更少人脸与更多观看相关；为观察性关联，未充分排除投放等因素，不能反推纯商品首图必胜。

注意力、偏好、购买意向、商品点击和订单分别记录。真正验证本账号方案需可比数据；创作阶段依据证据作选择，不承诺找到唯一最佳方式。
